# 🍋 Olemon Linux OS - Ultimate Edition (v2.2.0)

![Olemon Logo](logo.jpg)

**Olemon Linux OS Ultimate Edition** هو نظام تشغيل مبسط ومفتوح المصدر مبني على **Ubuntu**، مصمم خصيصاً لشركة **Olemon Incorporation**. يهدف النظام إلى توفير بيئة **Sandbox** معزولة، خفيفة جداً، وسريعة الأداء (CPU/GPU) للعمل عبر **WSL (Windows Subsystem for Linux)**.

### 🔐 تشفير Quantum Intelligence o9 (QI-o9)
تم دمج خوارزمية التشفير المبتكرة **Quantum Intelligence o9 (QI-o9)** داخل النظام. تعتمد هذه التقنية على مفهوم **الاحتمالات الصفرية واللانهائية** (Zero-Point & Infinite Probability)، حيث تستخدم مصفوفات احتمالية معقدة لتشفير البيانات بأسلوب يحاكي الحوسبة الكمومية، مما يوفر حماية فائقة للبيانات الحساسة داخل بيئة Olemon.

---

### 🧠 الوكيل الذكي (Olemon-Agent)
تم دمج **وكيل ذكاء اصطناعي كامل (Autonomous Agent)** داخل النظام. تتيح هذه الخاصية للمستخدمين التفاعل مع مساعد ذكي قادر على تنفيذ المهام، تحليل النظام، والأتمتة مباشرة من التيرمينال، مع دعم كامل لعمليات التشفير وفك التشفير باستخدام QI-o9.

---

### 🖥️ واجهة المستخدم (UI/UX Dashboard)
يأتي النظام بواجهة تحكم رسومية مبنية على الأكواد (Terminal-based Dashboard) توفر تجربة بصرية احترافية لمراقبة أداء النظام، استهلاك الموارد، وإدارة المهام بضغطة زر.

---

### 🛡️ التأمين البرمجي (Code-based Security)
تم تعزيز النظام بنظام تأمين برمجي متقدم يشمل:
- **Hardened Sandbox:** عزل كامل للعمليات والملفات الحساسة.
- **AppArmor & Auditd:** مراقبة وحماية النظام من التهديدات.
- **QI-o9 Encryption:** تأمين البيانات من خلال خوارزمية تشفير كمومية مبتكرة.

## 🚀 المميزات
- **QI-o9 Encryption:** تقنية تشفير كمومية مبتكرة.
- **Olemon-Agent:** وكيل ذكاء اصطناعي كامل ومستقل.
- **UI/UX Dashboard:** واجهة تحكم رسومية احترافية داخل التيرمينال.

- **شعار أحمر مميز:** يظهر الشعار الرسمي باللون الأحمر عند تشغيل التيرمينال.
- **خفيف جداً:** تم تجريد النظام من الإضافات غير الضرورية لضمان أقصى سرعة.
- **تكامل مع PowerShell:** يمكن تثبيته وتشغيله بضغطة واحدة من خلال Windows PowerShell.

## 🛠️ التثبيت السريع (PowerShell)

لفتح النظام وتثبيته مباشرة على جهازك، افتح **PowerShell** كمسؤول وقم بتشغيل الأمر التالي:

```powershell
irm https://raw.githubusercontent.com/mohamed-dev-labs/olemon-linux-os/master/install.ps1 | iex
```

## 💻 الإعداد الداخلي (داخل WSL)
بعد الدخول إلى النظام لأول مرة، قم بتشغيل الأمر التالي لتفعيل كافة الميزات المتقدمة:
```bash
curl -s https://raw.githubusercontent.com/mohamed-dev-labs/olemon-linux-os/master/setup.sh | bash
```

## 📂 هيكلة المشروع
- `install.ps1`: سكريبت التثبيت الخاص بـ Windows PowerShell.
- `setup.sh`: سكريبت تحسين الأداء، الأمان، ودمج الوكيل الذكي وتشفير QI-o9.
- `olemon_agent.py`: كود الوكيل الذكي وواجهة التحكم.
- `qi_o9_encryptor.py`: كود خوارزمية التشفير Quantum Intelligence o9.
- `logo_red.txt`: شعار ASCII الملون باللون الأحمر.
- `LICENSE`: رخصة المشروع (MIT).
